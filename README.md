# Автомойка «Пена»

Учебный проект для практических занятий №9-11 и контрольной работы №2 по дисциплине «Фронтенд и бэкенд разработка».

Посетитель сможет сравнить три программы по цене и длительности, выбрать экспресс-мойку кузова, уборку салона или комплексную мойку и записаться на удобное время.

## План работ

- Практика №9 - главная страница с навигацией и карточками программ на сетке Bootstrap.
- Практика №10 - каталог, страница программы и форма записи с выбором даты и времени.
- Практика №11 - проверка четырёх страниц и сдача контрольной работы №2.
