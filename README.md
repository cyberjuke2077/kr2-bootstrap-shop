# Автомойка «Пена»

Учебный сайт для практических занятий №9-11 по дисциплине «Фронтенд и бэкенд разработка». Тема КР №2 - разработка интерфейса на CSS-фреймворке. Автор - Белячков Артём, группа ЭФБО-11-25.

Посетитель сравнивает три программы, открывает состав работ и выбирает время мойки. Обе формы показывают учебное подтверждение в браузере. Адрес, часы работы и цены условные. Для проверки используйте вымышленные контакты.

## Запуск

Откройте `index.html` в браузере с включённым JavaScript и доступом к интернету. Bootstrap CSS и JS Bundle версии 5.3.8 загружаются с CDN. Файл `css/custom.css` подключён после стилей Bootstrap. [Документация Bootstrap](https://getbootstrap.com/docs/5.3/getting-started/introduction/).

## Практика №9. Сетка Bootstrap

Класс `container-fluid` задаёт ширину шапки, `container` ограничивает ширину содержимого. Ряды `row` и промежутки `g-*` используются на всех страницах. Карточки программ с классами `col-12 col-md-6 col-lg-4` располагаются в один столбец до 768 px, в два от 768 px и в три от 992 px. Мобильное меню раскрывает компонент Collapse.

## Практика №10. Компоненты и формы

- На всех страницах есть общий `navbar`. Активный пункт показывает текущую страницу или раздел.
- Каталог использует `card`, `badge`, `btn` и `accordion`. Кнопка «Заказать звонок» открывает `modal` с названием выбранной программы, а «Подробнее» ведёт к её описанию.
- Полная форма использует `form-control`, `form-select`, `input-group` для телефона и `form-check` для согласия. Компонент `alert` поясняет учебный режим. После проверки полей открывается окно с программой, датой, временем и стоимостью.

### Самостоятельные доработки

При переходе к записи со страницы программы услуга уже выбрана. Время рассчитывается для московского часового пояса. Начало сеансов - каждые 30 минут с 08:00. Форма предлагает только те сеансы, которые успеют закончиться к 22:00, и повторно сверяет время при подтверждении. Телефон можно вставить с пробелами, скобками и российским префиксом.

## Проверка перед защитой

1. Откройте каталог при ширинах 375, 768, 1024 и 1440 px. Сравните число карточек в ряду. На телефоне откройте меню и перейдите к контактам.
2. Откройте «Подробнее» у каждой программы. Сверьте фото, цену и таблицу работ. Нажмите «Записаться на мойку» и проверьте выбранную услугу.
3. Выберите завтрашнюю дату. Для экспресс-мойки последний сеанс начинается в 21:30, для комплексной - в 21:00. Отправьте пустую форму, затем заполните её вымышленными данными и сверьте подтверждение.
4. В каталоге откройте форму звонка, закройте её клавишей Escape и выберите другую программу. Проверьте обновление названия и раскройте вопросы о записи.

## Файлы проекта

- Четыре HTML-страницы содержат разметку и компоненты Bootstrap.
- `css/custom.css` задаёт цвета, типографику и оформление компонентов.
- `js/programs.js` содержит цены, длительность и состав программ для карточки услуги и форм. `js/product.js`, `js/catalog.js` и `js/order.js` отвечают за поведение соответствующих страниц. `js/validation.js` проверяет контактные данные в обеих формах.
- В `images/` лежат знак автомойки и три изображения WebP. Для изображений использован ImageGen. Сюжеты - кузов в пене, уборка тканевого сиденья и чистый седан после комплексной мойки.
