# Автомойка «Пена»

Учебный проект для практических занятий №9-11 и контрольной работы №2 по дисциплине «Фронтенд и бэкенд разработка».

На главной можно сравнить экспресс-мойку кузова, уборку салона и комплексную мойку по составу, цене и длительности. Адрес, расписание и цены учебные.

## Практика №9. Главная страница на сетке Bootstrap

Тема КР №2 - разработка интерфейса на CSS-фреймворке. Для этой работы используется Bootstrap 5.3.8. Стили и JS Bundle загружаются с CDN. Собственный CSS подключён после Bootstrap. [Пример подключения в документации Bootstrap](https://getbootstrap.com/docs/5.3/getting-started/introduction/).

- Шапка занимает всю ширину через `container-fluid`. Класс `container` выравнивает содержимое разделов, а `row` и `g-*` задают ряды и промежутки между колонками.
- На телефоне текст и фото первого экрана идут друг под другом, от 768 px - рядом. Мобильное меню раскрывает компонент Collapse из Bootstrap JS Bundle.
- В разделе программ классы `col-12 col-md-6 col-lg-4` дают одну карточку в ряд до 768 px, две от 768 px и три от 992 px. Преимущества в разделе «О мойке» с 768 px занимают три колонки.
- Кнопка «Выбрать мойку» ведёт к программам. По ссылке «Контакты» можно перейти к адресу и часам работы.

## Запуск и проверка

Откройте `index.html` в браузере с доступом к интернету. В режиме эмуляции устройств сравните сетку при ширине 375, 768 и 1024 px. На телефоне откройте меню и выберите «Контакты».

В Chrome проверены ширины 320, 375, 430, 767, 768, 991, 992, 1024 и 1440 px. Страница укладывается по ширине экрана. Кнопка первого экрана ведёт к программам, а первый переход по Tab открывает ссылку «К содержимому».

## Файлы

- `index.html` - главная страница.
- `css/custom.css` - цвета, типографика, фото первого экрана и оформление карточек.
- `images/drop.svg` - знак автомойки и иконка вкладки.
- `images/car-wash.webp` - иллюстрация первого экрана. Она создана в ImageGen по описанию тёмно-бирюзового седана с белой пеной на капоте в боксе ручной мойки.
